# Object Detection Using Python and OpenCV

## Project Overview
This project demonstrates object detection using Python and OpenCV.
It uses computer vision techniques to detect cars in video streams.

## Technologies Used
- Python
- OpenCV
- Jupyter Notebook

## Features
- Video processing using OpenCV
- Car detection in video frames
- Displaying detected objects using bounding boxes

## Project Files
- car_detection.ipynb - Jupyter Notebook containing the code.
- demo_video.mp4 - Project output demonstration.

## How to Run
1. Clone or download this repository.
2. Install the required libraries.
3. Open the notebook in Jupyter Notebook.
4. Run the cells to execute the project.

## Learning Outcomes
Gained practical experience in computer vision, video processing, and object detection using OpenCV.
